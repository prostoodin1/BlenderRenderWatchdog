# Blender Render Watchdog 2.6.0

Версия 2.6.0 убирает обязательный Tailscale, автоматически находит главные ПК в локальной сети и запоминает одобренные устройства. Для соединения через интернет теперь доступен опциональный SSH-туннель.

## Главное

- **LAN без дополнительных программ:** локальный рендер больше не требует Tailscale или другого стороннего клиента.
- **Автопоиск:** worker показывает доступные главные ПК в локальной сети и подключается к выбранному устройству.
- **Одноразовый код:** главный ПК может требовать шестизначный код только при первом подключении нового устройства.
- **Доверенное переподключение:** после подтверждения worker получает отдельный токен и больше не вводит код при следующих запусках.
- **Режим без кода:** хозяин может разрешить новым устройствам подключаться без кода в доверенной LAN.
- **Контроль видимости:** главный ПК можно показывать или скрывать в локальном поиске.
- **OpenSSH вместо Tailscale:** приложение устанавливает штатные компоненты Windows OpenSSH и создаёт скрытый туннель через ключ или `ssh-agent`.
- **Без пароля в коде:** формат `BRW4` переносит адрес, порт, пользователя и токен Watchdog, но никогда не сохраняет SSH-пароль.
- **Плавное подключение:** ожидание SSH выполняется в фоне и не замораживает интерфейс.

## Как подключить компьютеры в LAN

1. На главном ПК откройте **Network**, выберите **Local network (LAN)** и запустите контроллер.
2. Включите **Show this main PC on the local network**.
3. Выберите, должен ли главный ПК запрашивать одноразовый код у новых устройств.
4. На worker выберите найденный главный ПК, при необходимости введите показанный код и подтвердите подключение.
5. Следующее подключение использует сохранённое доверие автоматически.

Если UDP-поиск блокируется настройками сети или компьютеры находятся в разных VLAN, остаётся расширенный код `BRW2` с прямым адресом.

## SSH через интернет

На главном ПК установите OpenSSH Server из приложения и укажите адрес, доступный worker-компьютеру. На worker нужен OpenSSH Client и настроенный приватный ключ либо `ssh-agent`. SSH-сервер должен быть доступен извне — обычно через проброс TCP-порта или внешний SSH-сервер.

## Совместимость и безопасность

- старые локальные коды `BRW2` продолжают декодироваться;
- код `BRW3` сохранён для совместимости с установками 2.5.1;
- одноразовый LAN-код действует 10 минут и меняется после успешного подключения;
- UDP-объявления не содержат секретов;
- неверные попытки ввода кода ограничены по частоте;
- одновременно поддерживается до пяти render-worker.
