# Blender Render Watchdog 3.0.0

Версия 3.0 полностью перестраивает работу с проектами и render-устройствами: одна очередь и один активный `.blend`, постоянные группы компьютеров, пакетное распределение кадров и готовая SSH-ссылка для подключения через интернет.

## Новый единый Workspace

- проекты, активный рендер и группа устройств находятся на одном экране;
- один и тот же активный проект используется очередью, сетевым планом и мобильной панелью;
- повторное добавление `.blend` обновляет существующий проект вместо создания дубля;
- интерфейс стал легче: основные переходы не используют тяжёлые эффекты.

## Постоянные группы устройств

- главный ПК создаёт группу, доступную другим приложениям в локальной сети;
- поддерживаются открытые группы и подключение по одноразовому коду;
- стабильный ID установки не позволяет создавать дубликаты устройства после смены имени или IP;
- офлайн-устройства остаются в группе и показывают правильный статус;
- доверенный участник может принять роль главного ПК, если предыдущий координатор недоступен.

## SSH-приглашение одной кнопкой

- главный ПК создаёт отдельную пару ключей Ed25519 для render-группы;
- Windows OpenSSH Server, служба и правило брандмауэра настраиваются через системное подтверждение администратора;
- публичный ключ автоматически добавляется в фактический `authorized_keys` пользователя;
- ссылка `brw://join/...` переносит адрес, токен Watchdog и выделенный SSH-ключ;
- worker извлекает ключ в закрытый локальный файл и больше не требует ручного выбора ключа;
- приватная часть приглашения не сохраняется в обычном конфиге приложения.

SSH-сервер главного ПК должен быть доступен worker через интернет. Обычно для этого нужен проброс TCP-порта на роутере или внешний SSH-адрес.

## Рендер и производительность

- задания выдаются непрерывными пакетами по 10 кадров по умолчанию;
- доступны фиксированные пакеты 1/5/10/20/50 кадров и адаптация к фактической скорости worker;
- отдельный выбор CPU, GPU, CPU + GPU и автоматического режима;
- явный выбор Cycles backend: Auto, OptiX, CUDA, HIP, oneAPI или Metal;
- ETA рассчитывается по измеренной производительности всех активных устройств;
- один пакет запускается одним скрытым процессом Blender, поэтому CMD не мигает между кадрами.
